# run04 实验设计

## 与 run03 的唯一变量

prompt 里新增**第三条指令**：枚举「特征进入系统的路径」。

| | run02 | run03 | run04 |
|---|---|---|---|
| 输入材料 | SPEC | SPEC（同） | SPEC（同，md5 一致） |
| 指令1 全面覆盖 | ✅ | ✅ | ✅ |
| 指令2 维度交叉 | ❌ | ✅ | ✅ |
| **指令3 进入路径** | ❌ | ❌ | ✅ **新增** |

## 指令3 的措辞（刻意不提 bug、不提 ü、不提轻声）

> 对每一个特征，问：它有几种方式进入这个函数？
> 常见的两类是「由参数控制产生」和「由输入数据自带」。
> 请对每个特征，分别构造这两类用例。

## 判定

命中 = 存在把「自带该特征的数据」作为**输入参数**传入的用例，
且断言规范正确值，从而在 bug 版失败、修复版通过。
