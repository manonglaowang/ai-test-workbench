# AI 能不能发现真实项目里的 bug？

四轮可复现对照实验。全部代码与原始数据开源。

## 主要文章

**[我让 AI 写了 2392 个测试用例，前三轮一个 bug 都没抓到](AI生成测试用例的四轮实验.md)**

前三轮 1373 个用例真 bug 零命中；第四轮补上三条 prompt 指令后命中 17 个。
副产物：变异杀伤率最高的两轮，恰恰是一个 bug 都没抓到的两轮。

**[变异杀伤率 81%，一个 bug 没抓到](变异杀伤率81%一个bug没抓到.md)**

覆盖率和变异杀伤率测的不是「能不能发现 bug」。五组数据 + 两个项目的对照。

## 实验数据

| 轮次 | 变量 | 命中真 bug | 误报 | bug 固化 | 变异杀伤率 |
|---|---|---|---|---|---|
| run01 | 给源码 | ❌ 0 | 7 | 🔴 2 | 81.1% |
| run02 | 给规格 | ❌ 0 | 2 | ✅ 0 | 81.1% |
| run03 | +维度交叉 | ❌ 0 | 17 | ✅ 0 | 51.4% |
| **run04** | **+进入路径** | ✅ **17** | 6 | ✅ 0 | 67.6% |

对照组：项目自带 141 个测试 = 56.8%，且在 bug 版**全部通过**。
